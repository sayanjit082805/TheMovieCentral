# TheMovieCentral

TheMoveCentral is a web based application which provides various details about thousands of movies, built using NextJS.

## Features

- Search details for an almost endless number of movies.
- Built using [Aceternity UI](https://ui.aceternity.com/)
- Powered by [tmdb](https://themoviedb.org).

## Prerequisites

- Node.js (v-14 or later)
- npm or yarn
- TMDB API key

## Installation

### Initial Setup

First, head over to [tmdb](https://www.themoviedb.org/) and generate your own API-Key, it's completely free. Then, follow the below mentioned steps :

- Clone the repository.

```bash
git clone https://github.com/sayanjit082805/TheMovieCentral.git
cd TheMovieCentral
```

- Install dependencies with `npm install`

- Create a .env file in the root directory of the project and enter your api key like this:

```
NEXT_PUBLIC_TMDB_API_KEY = 'your-api-key'
```

### Running

- Start the application with `npm run dev`.
- Next, open your browser and navigate to `http://localhost:3000`.
